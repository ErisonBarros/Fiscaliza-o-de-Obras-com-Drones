# Material Completo do Curso: Fiscalização de Obras com Drones

## 📚 Visão Geral

## 📝 Como Usar os Slides

Os slides foram criados em formato Markdown para facilitar a edição e conversão. Você pode:

### Opção 1: Converter para PowerPoint

1. Use ferramentas como **Marp** ou **Pandoc** para converter Markdown em PPTX
2. Comando exemplo com Pandoc:
   ```bash
   pandoc Slides_1.1_Introducao.md -o Slides_1.1_Introducao.pptx
   ```

### Opção 2: Usar Google Slides

1. Copie o conteúdo de cada slide
2. Cole em uma apresentação do Google Slides
3. Formate conforme necessário

### Opção 3: Usar Marp (Recomendado)

1. Instale a extensão Marp para VS Code
2. Abra os arquivos `.md` dos slides
3. Exporte diretamente para PDF ou PPTX
